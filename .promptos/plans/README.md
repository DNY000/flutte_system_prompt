# Plans (Flutter / mobile)

Store **architecture and execution plans** produced after `plan` mode or roadmap routes.

**Required:** read `../PLANNING_WORKFLOW.md` before treating any work item as complete.

- **`item-completion-plan-template.md`** — every time you “finish an issue” (small feature, route change, eval, skill, …).
- **`approved-plan-template.md`** — large architecture / migration plans (module, add-to-app, sync, …).
- Link related `route_id`, `output_contract`, and affected `lib/` modules.
- Call out **platform-specific** work (Gradle, Xcode, entitlements, Play/App Store).

Approved plans that become team policy should spawn a `memory-drafts/` entry and eventually `docs/ai/memory/decisions.md`.
