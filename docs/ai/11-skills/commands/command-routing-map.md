# Command To Route Family Map

| command | primary route families | default output contracts |
| --- | --- | --- |
| `ask` | research, decision, architecture review | `research-brief-v1`, `decision-matrix-v1`, `review-report-v1` |
| `plan` | architecture, ai-system roadmap, BA | `architecture-decision-v1`, `improvement-roadmap-v1`, `implementation-plan-v1` |
| `review` | review, security, performance, debug | `review-report-v1` |
| `execute` | code, security, performance, test, CI | `implementation-plan-v1`, `pipeline-change-v1` |
| `ship-check` | CI/CD, test, security, performance | `pipeline-change-v1`, `test-plan-v1`, `review-report-v1` |
