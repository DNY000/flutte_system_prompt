# Prompt And Agent Completion Master Plan

This program completes the prompt system through five deliberate passes.

## Goal

Finish the prompt operating system for:

- Flutter and mobile engineering work
- prompt-system design
- AI agent design
- MCP and research workflows
- evals and regression control

## Completion Criteria

- all major route families exist
- task prompts exist for Flutter, AI prompt design, agent design, evals, research, and debugging
- output contracts cover design, decision, implementation, review, triage, research, and roadmap work
- route regression checks exist
- memory and MCP boundaries are operational
- compact rules and answer policies exist for external use

## Five Passes

1. `foundation-and-ai-coverage.md`
   Core architecture, routes, contracts, and missing AI-system foundations.
2. `mcp-memory-and-measurement.md`
   Prompt engineering, AI agent, MCP, and eval packs.
3. `flutter-coverage-expansion.md`
   Flutter coverage expansion: debug, add-to-app, web, desktop, plugin authoring, offline-first.
4. `quality-safety-and-governance.md`
   Quality hardening: regression tests, benchmarks, memory workflow, release readiness.
5. `production-hardening-and-baseline.md`
   Final review, compact variants, answer policies, and production release gate.

## Work Order

- run each pass in sequence
- after each pass, review defects before expanding scope
- convert stable decisions into memory only after review
- do not start broad automation before route and eval quality are stable
