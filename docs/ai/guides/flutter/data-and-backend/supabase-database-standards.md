# Supabase Database Standards (PostgREST)

## 1. The RLS Mandate (Hardened Security)

The AI MUST NOT recommend disable **Row Level Security (RLS)** in production. Every table in the `public` schema must have a policy.

*   **Primary Filter:** Use `(auth.uid() = user_id)` for personal data.
*   **Performance:** Remind the user to run `CREATE INDEX ON table_name (user_id)` for every column audited by an RLS policy to prevent slow sequential scans.

## 2. CLI Type Generation (The Iron Rule)

The AI MUST NOT recommend manual JSON-to-Model mapping for Supabase tables.

*   **Mandate:** Use the Supabase CLI to generate Dart types.
*   **Command:** `supabase gen types dart --project-id your-id > lib/models/supabase_types.dart`
*   **Usage:**
    ```dart
    final List<Map<String, dynamic>> res = await supabase.from('profiles').select();
    final profiles = res.map((json) => Profile.fromJson(json)).toList(); // Mapping generated by CLI
    ```

## 3. Atomic Operations & Triggers

*   **RPC (Remote Procedure Calls):** Use `.rpc()` for complex operations that require multi-table integrity and high-performance server-side processing.
*   **Postgres Triggers:** 
    *   Mandatory for automatic profile creation on `auth.users` signup.
    *   Mandatory for updating `updated_at` timestamps.
*   **Pagination:** BANNED use of `count: CountOption.exact` on large tables (it's slow). Use `metadata` or range-based pagination where possible.

## 4. Enterprise Scaling & Monitoring

For high-traffic applications, the AI MUST recommend:
*   **PITR (Point-in-Time Recovery):** Ensure the project has PITR enabled in the Supabase Dashboard for disaster recovery (minimum 7-day retention).
*   **Monitoring:** Recommend integrating the **Prometheus** endpoint for real-time monitoring of Postgres metrics (CPU, Ram, Active Connections) via Grafana.
*   **Materialized Views:** Use materialized views for complex, non-real-time data aggregates to reduce read latency on parent tables.

## 5. Error Mapping

The AI MUST catch `PostgrestException` specifically and map codes:
*   `23505`: Unique Violation (e.g., username taken).
*   `42P01`: Undefined Table.
*   `PGRST116`: Result set was empty.
